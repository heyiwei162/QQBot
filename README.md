# 🤖 QQ机器人
基于 qq-botpy（官方开放平台 SDK）开发的 QQ 机器人，支持群聊、私聊交互，内置米游社 COS 图库随机推送、复读机、按钮交互、@机器人指令、好友事件监听等功能。

> ⚠️ 重要提醒：本项目使用 QQ 开放平台机器人，仅可用于合规测试，严格遵守《QQ 开放平台开发者协议》，禁止用于违规刷屏、色情内容分发、商业营销等行为。

## ✨ 功能清单
### 📢 基础交互
- 群 @机器人触发菜单、问好、随机图片指令
- 私聊消息自动响应
- 好友新增 / 删除事件记录
- 机器人入群、退群事件处理，自动发送欢迎语

### 🔁 复读机功能
- 群内开启 `/复读机`，自动复读群成员消息
- 支持图片附件复读（转换为 Markdown 图片格式）
- `/退出复读机` 关闭复读
- 过滤机器人自身消息，防止自循环刷屏

### 🖼 COS 图库系统
- 本地 `cos_all.json` 存储 COS 数据
- `/随机C图`：随机抽取单张图片推送
- `/随机C帖`：随机推送整套帖子（标题 + 时间 + 多张图片）
- 配套交互按钮，一键再次刷新图片

### 🎛 按钮交互（Interaction）
- 点击菜单按钮触发指令，无需手动输入命令
- 支持群聊、私聊双通道按钮响应
- 问好、随机 COS、打开功能菜单快捷入口

### 🛡 其他
- 消息清洗：自动移除 @标签、QQ 表情标签防止接口报错
- 事件日志完整输出，方便调试
- 消息发送简易异常兼容

## ⚙️ 环境部署
### Python 版本
推荐 Python >=3.10

### 安装依赖
```bash
pip install botpy
```
配置账号信息
打开 main.py，找到启动代码：
python
运行
client.run(appid=APPID, secret=APPSECRET)
替换为你在【QQ 开放平台】申请机器人得到的 AppID 和 AppSecret。
同时修改代码内机器人自身 app_id 常量。
启动机器人
```bash
python main.py
```
📝 使用指令（群聊）
所有指令支持直接发送 或者 @机器人 + 指令
表格
指令	功能
>/菜单	弹出功能菜单
>/问好	Ciallo 打招呼
>/复读机	开启复读模式
>/退出复读机	关闭复读模式
>/随机C图	随机一张 COS 图片
>/随机C帖	随机一套 COS 帖子
